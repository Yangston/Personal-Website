The site has three public route families: `/`, `/projects`, and `/photography`. Astro owns routing and durable HTML. A small framework-neutral canvas controller progressively enhances the travel atlas; country and city pages remain static galleries.

Sightline is a separate repository and deployment. Camera localization, pose reconstruction, provider viewers, scene payloads, and their research evidence must not be added back to this portfolio.
