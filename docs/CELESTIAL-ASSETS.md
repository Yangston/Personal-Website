# Celestial artwork

The four portfolio scenes share the authored composition in `src/lib/portfolio-universe/scene-manifest.ts`. Runtime images are local assets under `public/media/site/celestial`; the renderer needs no provider credentials or remote asset service.

## Generated artwork

The cloud bank, foreground bank, fine wisps, lavender nebula, marble planet, and stardust veil were generated with the built-in ImageGen tool for this portfolio on 2026-09-06, using the supplied reference's ivory/champagne illumination, lavender shadows, and feathered silhouettes. Each asset was generated separately with true transparency. No text or navigation is baked into the imagery. The stardust veil provides a quiet lavender backdrop behind the independently rendered constellation stars.

Landscape plates use 1536×1024 and 768×512 alpha WebPs. The marble planet uses 1024×1024 and 512×512 variants. Sharp resizing and WebP compression preserve alpha. The fine-wisp asset also provides the diffuse nebula halo. Existing `pearl-moon-v2.webp` supplies small decorative satellites.

Selected originals remain under ignored `.private/celestial-assets/`; only optimized display variants are published. Replace references only after checking silhouettes, edge halos, lighting, and foreground overlap in the actual scene.

## Cloudscape clusters - current composition

The current environment uses the two images selected by the user: the first dense cloudscape master and the bright spiral nebula originally delivered with a painted checkerboard. The subsequent synthetic cloud variants are not used.

`scripts/celestial/extract-cloudscape.mjs` prepares the assets from four ignored originals in `.private/cloudscape-v3/originals`: `cloudscape.png`, `cloud-matte.png`, `nebula.png`, and `nebula-matte.png`. Built-in ImageGen produced the source artwork and the extraction mattes. The processor retains source RGB pixels, removes the nebula's checker background through its matte and edge cleanup, and separates 22 cloud clusters with overlapping, feathered boundaries. It does not synthesize replacement cloud texture.

The 22 independently positioned cloud images, nebula, and distant atmosphere have two responsive variants each: 48 WebPs under `public/media/site/celestial/cloudscape-v3`, totaling approximately 1.19 MB. Each asset is exported at its native crop resolution and half-width; none is upscaled. `src/data/cloudscape-artwork.json` is generated by the extraction command and records the exact source dimensions and URLs. Do not edit that catalog manually.

The current scene contains 25 desktop / 16 mobile artwork planes across eight depth bands, including the existing marble planet. The repeated moon planes have been replaced by the distinct native bodies described below. Structural priority preserves the atmosphere and major cloud formations when decorative detail is reduced. Explicit mobile placements feed the same first-paint, GPU, and context-loss projection paths. The distant atmosphere fills gaps revealed between clusters; it is not the sole cloud layer.

The opening uses the extracted upper-left and lower-left formations with its existing 1600 ms timing and dismissal behavior. Camera destinations, constellation geometry, navigation, and photography are unchanged. Rendering limits are 44 desktop / 32 mobile draw calls; the existing pixel-buffer and frame-time gates remain in effect. Current measured results belong in `design-qa.md`.

Rebuild with `node scripts/celestial/extract-cloudscape.mjs`, then inspect the nebula edges and cloud overlaps against the approved sources before publishing. Supporting evidence and rejected drafts stay private.

## Interactive regions and secondary bodies - 2026-09-07

The approved cloud and nebula WebPs are unchanged. `node scripts/celestial/prepare-interaction-contour.mjs` samples the approved nebula alpha into `src/data/nebula-hit-contour.json`. Regenerate this contour when replacing the nebula texture; do not hand-edit it. The same normalized contour supplies initial HTML, live projected input, and fallback navigation. Localized illumination and bounded UV deformation use the original texture in one shader pass; no extra nebula images are required.

`body-manifest.ts` defines five unique decorative objects: a ringed planet, a cratered crescent moon, and chalk, iron, and ice asteroids. Each has an individual seed, silhouette, texture, and pose. Built-in ImageGen produced these five cutouts using the approved marble planet and cloudscape as direct style references; a lighting-only pass establishes the moon crescent. Generated opacity mattes remove the painted checker backgrounds while preserving source RGB. The GPU and HTML fallback use the same responsive artwork. The desktop set contains all five; mobile retains the ringed planet and chalk asteroid. The existing large marble planet remains in place.

`node scripts/celestial/prepare-secondary-bodies.mjs` publishes ten versioned 1024px/512px alpha WebPs under `public/media/site/celestial/bodies-v1` and the generated dimension catalog `src/data/celestial-body-artwork.json`. No image is enlarged. Mask cleanup fills enclosed crater holes on solid bodies while preserving the ring openings. Sources, mattes, and exact generation/edit prompts stay in ignored `.private/interactive-world/body-originals` and `body-prompts.md`.

Shared clock samples drive body drift, localized nebula folds, stellar shimmer, and one infrequent shooting star. Reduced motion uses steady highlights and stationary bodies. Decorative geometry is reduced before structural cloud artwork. The Home silhouette links remain native HTML above the canvas, with accessible names, real URLs, and contour focus indicators.

## NASA Earth imagery

- **Surface:** [Blue Marble Next Generation, June 2004, topography and bathymetry](https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-topography-bathymetry/). NASA Earth Observatory, Reto Stöckli. Original: 5400×2700.
- **Clouds:** [Blue Marble cloud coverage](https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57747/cloud_combined_2048.jpg). NASA GSFC, Reto Stöckli; enhancements by Robert Simmon. Original: 2048×1024.
- **Night lights:** [Black Marble 2016](https://eoimages.gsfc.nasa.gov/images/imagerecords/144000/144898/BlackMarble_2016_01deg.jpg). NASA Earth Observatory, Joshua Stevens; Suomi NPP VIIRS data from Miguel Román, NASA GSFC. Original: 3600×1800.

Use follows [NASA's imagery and media guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/). NASA imagery does not imply endorsement. The portfolio modifies its presentation with warm color grading, subtle gold emission, clouds, and geographic selection overlays.

The day, night, and cloud maps are separate 2:1 equirectangular textures, optimized to 2048×1024 and 1024×512. The geographic country-state mask remains independently generated from the public world atlas. A half-turn texture-space correction preserves the atlas's longitude convention; do not rotate geographic picking coordinates to adjust the artwork.

Prepare the downloaded source files and the static orthographic fallback views:

```powershell
node scripts/celestial/prepare-earth.mjs --download
```

To rebuild using existing ignored originals in `.private/celestial-sources`, omit `--download`. Generated outputs include six texture variants and Home/Travel fallback views. Inspect the fallback/GPU handoff after changing the texture palette or geographic orientation.

## Golden project sky - 2026-09-09

`public/media/site/project-sky.svg` is authored vector artwork: mauve/charcoal gradients, a radial transparency mask, and deterministic SVG turbulence. It replaces the old mist plate behind Projects. Both DOM and WebGL load this local asset. Nine depth plates reuse the existing bridge, wall, bottom puff, and crown textures.
