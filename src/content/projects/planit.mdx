## A quieter calendar

PlanIt combined a calendar and task list in one Django application. It used PostgreSQL for persistence and a deliberately minimal browser interface.

The project now serves as a useful contrast to this portfolio rebuild: a backend is valuable when the product owns mutable user data, but unnecessary for a mostly static body of editorial work.
